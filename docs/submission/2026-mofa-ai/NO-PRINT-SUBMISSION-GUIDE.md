# ClaimGate ODA 무출력 제출 방법

1. `claimgate-oda-participation-application.md`의 대괄호 개인정보를 수정한다.
2. `SIGNATURE-PAD.html`에서 서명하여 `signature.png`를 같은 폴더에 저장한다.
3. Windows에서 `EXPORT-APPLICATION-PDF-WINDOWS.cmd`를 더블클릭한다.
4. 생성된 참가신청서 PDF를 열어 정보와 서명을 확인한다.
5. 제품 기획서와 개인정보 동의서도 개인정보·서명을 반영한다.
6. 최종 PDF 3개를 제출한다.

상세 절차는 `WINDOWS-EDITING-GUIDE.md`를 참조한다.
