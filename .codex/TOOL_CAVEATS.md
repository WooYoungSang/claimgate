## `devos_acquire_fencing_token`

Issue monotonic fencing token or UoW/file-set lease to prevent stale writes in multi-agent scenarios.

호출 경로 / 알려진 함정 / 동치 도구
- 호출 경로: MCP wire -> legacy collab fencing when resource_kind==''; otherwise lifecycle.concurrency_lease LeaseRegistry for uow/file_set leases; both paths call context_devos.concurrency_bridge for advisory cross-check.
- 알려진 함정: file_paths overlap returns conflict_reason=FILE_OVERLAP; registry is authority and FM fields are advisory mirrors; cross_primitive_conflict is advisory and does not fail-close the acquire.
- 동치 도구: devos_release_fencing_token for release; no separate bridge tool.

- 알려진 함정: CodeSymbol semantic vector lane은 code-like query에서 `source="codesymbol"`, `role="code_signature"` item을 반환한다. Cypher와 defensive result filter 모두 resolved `project_id` scope를 강제해 sibling project code cross-project leak을 차단한다.
